# Stratégies images

Collection d'images de référence sur les patterns chartistes et les stratégies de trading (Fair Value Gap, Order Block, figures de retournement/continuation, bougies japonaises). Matériel de référence visuelle, pas du code — rien dans ce dossier n'est lu par un script du dépôt.

## Origine

Captures d'écran et illustrations issues de réseaux sociaux (MarketSniperR, Before Noise, TradingMafia et autres), rassemblées comme matériel de référence pour l'analyse technique — à ne pas confondre avec les 13 détecteurs de patterns réellement implémentés dans `engine/patterns/` (voir `CLAUDE.md` et `George_AnalyseTechnique_Kabbaj_Synthese.md` pour ce qui est effectivement câblé dans le code).
